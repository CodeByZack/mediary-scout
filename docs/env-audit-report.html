🏗️ 环境变量优先级模型

大部分配置项的读取遵循以下优先级（高 → 低）： 

┌─────────────────────────────────┐
│   DB 设置（设置页持久化）          │  ← 最高优先级
├─────────────────────────────────┤
│   env 变量（.env / docker-compose）│  ← 部署级配置
├─────────────────────────────────┤
│   默认值（代码内硬编码）            │  ← 最终回退
└─────────────────────────────────┘

// 示例：PanSou 地址解析
PANSOU_BASE_URL =
  DB 设置 ??
  env.PANSOU_BASE_URL ??
  "https://so.252035.xyz"

// 示例：AI 模型配置
API Key =
  DB 设置（设置页） ??
  env.AGENT_MODEL_API_KEY
审计范围：apps/web/, packages/workflow/src/, deploy/, workers/, 根目录配置文件
排除：node_modules/, dist/ (仅标注死文件), 测试文件中的临时赋值
